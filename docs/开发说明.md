# 源码构建

需要 JDK 21、Android SDK 36。项目使用 Gradle Wrapper；在自己的 `local.properties` 填写 SDK 路径。

```sh
./gradlew assembleDebug
./gradlew testDebugUnitTest --tests 'app.resound.analysis.*'
```

调试包位于 `app/build/outputs/apk/debug/app-debug.apk`，签名与发布包不同，不保证覆盖已有应用。正式签名文件由维护者保存在仓库外，未随源码提供。

`app/src/main/assets` 中仅有通用模型、词表和提示词；不是个人声纹或用户记录。本地转写的大模型由用户另行下载。第三方运行库及模型见 `third-party/` 与各模型目录内的许可。

公开版本以当前源码快照起始，不包含本机开发历史、私人交接文件或真实设备资料。
