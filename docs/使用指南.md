# 文鱼使用指南

文鱼是一款安卓记录与回顾工具。个人模式用于记录、查原话、整理记忆和待办；分析模式围绕主动提供的人物与事件资料，辅助回顾和准备沟通。资料优先保存在本机，转写和整理可按需配置外部服务。AI的解释需要回到材料核对。

## 开始使用

允许麦克风和通知后，在个人模式首页点“开始聆听”。首页状态分别反映采集、转写和整理进度；正在收音不代表文字或记忆已生成。需要关闭聆听时长按停止按钮1.5秒，临时停一会儿用旁边的暂停入口。

在“设置 → 原话与转写”选择本机或云端转写。本机识别需要先准备模型；云端需要填写对应服务的配置。转写质量受音量、环境、口音和重叠说话影响，重要内容请回听原音并核对文字。

在“设置 → 共用模型”填写整理所用服务，之后可生成记忆、待办或使用问问。只查看页面、建档和管理已有资料无需模型密钥。密钥在自己的设备中填写，不放进公开资料。

## 个人模式的六个页面

| 页面 | 用法 |
|---|---|
| 原话 | 按日期和两小时时段查转写，定位播放原音；需要长期留存时按天保存或导出 |
| 今天 | 查看聆听状态、当天节奏与时间线，按需整理记录 |
| 记忆 | 回看已整理的事件和分类内容，也可从这里把某一天归档到电脑 |
| 问问 | 围绕自己的已有资料提问，并回到原话核对答案 |
| 待办 | 查看和处理已提取事项，核对原话及时间 |
| 设置 | 配置录音后台、转写、模型、声纹、技能、足迹及备份 |

## 声纹登记

“设置 → 声纹与人物”可登记本人或其他获同意人物的声音。本人登记提供三段朗读文字，每轮15秒；有效样本至少3段、累计30秒。用平常说话的声音录入，保持环境安静并避免多人同时说话。声纹用于尝试区分身份，登记完成不代表每一句都能识别正确。

## 人物与事件

点击模式标题进入分析模式。先新建人物，填写昵称及已知信息；不清楚的字段可以跳过。通过补充文字、导入录音或主动选择个人记忆积累资料。个人记录不会仅因为出现人名就自动成为该人的已确认档案。

人物独立录音与个人全天采集是两个入口。录音保存或音频导入后，可点“本地转写”生成文字；转写保存与智能分析分开执行。点击“智能分析”核对人物和材料范围，再生成报告。报告中的判断、原句依据和未知信息需要由用户检查，可以接受、忽略或重新查看待确认项。

事件可独立创建，并关联已建立的人物。填写已知时间、类别和发生内容；不把缺失时间或猜测写成已知事实。问问与技能同样依据实际选择的材料工作。

## 足迹与设置

0.1.2提供“设置 → 识别 → 足迹”，定位默认关闭。按需开启后可查看路线、停留和地名；地名服务会按所选方式处理坐标。整理时是否参考地点、环境音另行选择，默认关闭。足迹明细目前不包含在电脑按日归档中。

个人整理技能与分析技能分开配置。后台运行还需要逐人物授权，受网络和系统节电影响，不保证准点。版本页中尚未接入文鱼发布通道的功能不能视作自动更新已经可用。

## 手机归档到电脑

1. 电脑打开灵犀桥工作区，进入“手机”，点“开启手机接收”，查看地址和临时配对码。
2. 手机在“记忆”选择日期，点“归档这一天到电脑”，核对原话、待办及日记范围，填写地址和配对码后发送。
3. 手机收到有效回执后，电脑即可查看对应日期的原话、笔记、统计和所选待办。相同内容重复发送不会重复增加，新版本另存快照。

这是用户主动发起的按日归档，不是持续双向同步。优先使用允许设备互访的可信网络；部分校园或公共Wi-Fi隔离设备，需要更换网络。USB转发属于单独配置的连接方式，拔线后不继续可用。

## 备份与版本

“设置 → 数据备份”的全局备份覆盖个人文字库、技能、分析文字和被引用的分析原音。个人全天采集原音需按原有保存或导出规则另行保护；不能把文字备份当作全部原音的完整备份。分析JSON导出只包含分析文字。恢复前核对范围，两份都新增了资料时不可直接互相覆盖。

当前手机版本为0.1.3、Android10及以上、arm64，实际验收设备为iQOO Neo 9。桌面预览版为0.2.2。真实模型质量、长时后台、定位耗电与其他机型需要按实际使用验证。
